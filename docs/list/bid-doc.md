# 标书制作与文档自动化

> Word 模板批量生成、排版与目录页码、格式检查、导出 PDF。

共 **5** 个条目。英文名：Bid Document Automation。

| 项目 | 说明 | 信息 |
| --- | --- | --- |
| [OpenBidKit 易标](https://yibiao.pro) | 开箱即用的 AI 写标书工具：素材知识库、逐章生成、标书查重与废标项检查，桌面端和网页都能跑。<br><sub>场景：从招标文件提取评分点，逐章生成技术标初稿；把历史标书沉淀成素材库，避免每次重写；提交前跑一遍废标项检查与雷同检查</sub> | 应用 · JavaScript · AGPL-3.0 · ★ 3.2k |
| [docxtemplater](https://docxtemplater.com/) | 用占位符把数据灌进 Word 模板，支持循环表格与条件段落，是批量生成投标函、承诺书、资格审查表的主力方案。<br><sub>场景：一个项目数据生成整套标书表单；批量套打投标函与法定代表人证明</sub> | 库 · JavaScript · MIT · ★ 3.6k |
| [python-docx](https://python-docx.readthedocs.io/) | 读写 .docx 的标准库，能改样式、页眉页脚、目录与表格，适合在生成标书后做格式规整与字段替换。<br><sub>场景：批量替换标书中的项目名称与日期；生成后统一调整字体、行距与页码</sub> | 库 · Python · MIT · ★ 5.8k |
| [docx4j](https://www.docx4java.org/) | Java 生态里最完整的 Office Open XML 处理库，能直接 docx 转 PDF、做文档合并与域代码替换，适合已有 Java 后台的系统集成。<br><sub>场景：服务端把标书 docx 转成 PDF；合并多个章节文件生成完整投标文件</sub> | 库 · Java · Apache-2.0 · ★ 2.4k |
| [Mammoth](https://github.com/mwilliamson/mammoth.js) | 把 .docx 转成语义干净的 HTML，丢掉 Word 那堆杂乱样式，适合做标书在线预览与结构化抽取的前置步骤。<br><sub>场景：投标文件网页预览；先转 HTML 再提取章节标题层级</sub> | 库 · JavaScript · BSD-2-Clause · ★ 6.3k |

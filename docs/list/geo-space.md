# GIS 与空间数据

> 地图引擎、坐标转换、工地选址、地形与遥感。

共 **3** 个条目。英文名：GIS & Geospatial。

| 项目 | 说明 | 信息 |
| --- | --- | --- |
| [QGIS](https://qgis.org/) | 桌面 GIS 的事实标准，看地形、算运距、画工地范围、做场平分析都在里面完成，插件可脚本化。<br><sub>场景：项目选址与周边环境分析；土方量与运距测算</sub> | 应用 · C++ / Python · GPL-2.0 · ★ 14.7k |
| [Cesium](https://cesium.com/platform/cesiumjs/) | 浏览器里的三维地球引擎，能把 BIM 模型叠到真实地形上，适合做方案汇报与场地三维展示。<br><sub>场景：倾斜摄影与地形三维展示；模型放到真实场地里汇报</sub> | 库 · JavaScript · Apache-2.0 · ★ 15.9k |
| [OpenLayers](https://openlayers.org/) | 二维地图前端库，能对接各种瓦片与 WMS 服务，做项目分布地图与行政区划钻取足够稳。<br><sub>场景：中标项目全国分布地图；按行政区划筛选项目</sub> | 库 · JavaScript · BSD-2-Clause · ★ 12.6k |

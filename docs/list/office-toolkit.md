# 通用办公与文档工具

> PDF 处理、OCR、Excel 表格、批量文件操作——投标日常的高频基建。

共 **5** 个条目。英文名：Office & Document Toolkit。

| 项目 | 说明 | 信息 |
| --- | --- | --- |
| [OCRmyPDF](https://ocrmypdf.readthedocs.io/) | 给扫描版 PDF 补一层可搜索的文字，原件外观不变；扫描标书加文字层后就能全文检索与复制。<br><sub>场景：扫描标书批量加文字层；归档件转可检索 PDF</sub> | 命令行 · Python · MPL-2.0 · ★ 35.2k |
| [SheetJS](https://sheetjs.com/) | 跨端电子表格读写库，能把 xlsx 当数据库一样解析和生成，用来对接清单报价表、投标报价汇总表特别省事。<br><sub>场景：解析投标人上传的报价 Excel；服务端生成报价汇总表</sub> | 库 · JavaScript · Apache-2.0 · ★ 36.3k |
| [Univer](https://univer.ai/) | 可嵌入的在线表格与文档引擎，支持公式、协同与导入导出，适合在系统里直接打开并编辑报价表。<br><sub>场景：系统内嵌在线编辑 xlsx；多人在线核对工程量清单</sub> | 库 · TypeScript · Apache-2.0 · ★ 22.8k |
| [qpdf](https://qpdf.readthedocs.io/) | PDF 结构级处理工具，无损合并拆分、旋转页面、加密解密、修复损坏文件，批量整理标书附件很可靠。<br><sub>场景：把多个章节 PDF 合成完整投标文件；按大小限制拆分上传文件</sub> | 命令行 · C++ · Apache-2.0 · ★ 5.5k |
| [flyfish file-viewer](https://file-viewer.app) | 纯前端预览 275+ 种文件：Office、PDF、OFD、CAD、3D、压缩包，不需要服务端转换。<br><sub>场景：系统里嵌附件预览，不走后端转码；投标文件（PDF/OFD/Office）统一在线打开</sub> | 库 · TypeScript · Apache-2.0 · ★ 2.7k |
